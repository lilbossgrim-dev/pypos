# Support

- **Questions and how-to:** open a GitHub Discussion (if enabled) or an issue labelled
  `question` at `https://github.com/<TU_USUARIO>/<TU_REPOSITORIO>`.
- **Bugs:** open an issue using the bug template; include your Python version, OS, database and a
  minimal reproduction. Run `pypos doctor` and include its output.
- **Security problems:** see [SECURITY.md](SECURITY.md) — do not file them publicly.
- **Documentation:** [docs/index.md](docs/index.md) and [docs/troubleshooting.md](docs/troubleshooting.md).

This is a community project without a support SLA.
